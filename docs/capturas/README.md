# Capturas de la interfaz

El repositorio incluye una **vista ilustrativa** en `vista-inicio.svg`, construida con la imagen y los textos de la interfaz.

Antes de la entrega final, agrega aquí una **captura real** de AGROPIDA funcionando en el navegador como `inicio.png`. No incluyas cuentas, correos, contraseñas ni información real de ejemplares. Una captura real del panel puede guardarse como `panel.png`.
