# AGROPIDA v1.0.0 — Entrega académica

**Fecha:** 18 de noviembre de 2026.

## Incluye
- Página principal y acceso demostrativo.
- Panel con resumen visual.
- Gestión de ejemplares y fotografías.
- Registro y seguimiento de eventos de cuidado.
- Interfaz adaptable, marca verde/dorado.
- Código organizado, documentación, pruebas básicas y servidor opcional.

## Limitaciones
- Los datos se almacenan en el navegador.
- No hay cuentas verificadas en servidor.
- No hay IA conectada ni diagnóstico veterinario.
- La captura real y el video de demostración son entregables opcionales que deben añadirse cuando estén validados.

Este archivo **no** crea automáticamente un GitHub Release ni una etiqueta.
